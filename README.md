# Детейлинг: десять разных сайтов

Демонстрационные сайты Romanc, Geringer, ЛК, Crystal, Green, Мастер Вмятин, Культ, AMG, Юни Авто и Magnum CWS.

Каждый сайт — самостоятельный HTML с встроенными изображениями, стилями и JavaScript. Шрифты загружаются через Google Fonts; предусмотрены локальные запасные шрифты.

Формы демонстрационные и не отправляют данные. Для записи доступны телефонные ссылки. Цены — ориентиры, итоговый объём и стоимость уточняются в студии. Изображения обозначены как атмосферные визуализации; это не фотографии выполненных работ компаний.

Главная страница содержит ссылки на все десять сайтов.
